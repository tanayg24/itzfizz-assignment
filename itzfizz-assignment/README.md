# Itzfizz Scroll-Driven Hero — Assignment

A responsive React landing page concept built with Vite, CSS, GSAP, and ScrollTrigger.

## Features
- Animated headline and hero graphic on load
- Scroll-scrubbed hero title and abstract artwork
- Scroll-triggered statistic cards, manifesto text, and service rows
- Responsive mobile layout and reduced-motion support
- Semantic sections, accessible labels, and lightweight SVG icons via Lucide

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Deploy
Push this folder to a GitHub repository and import it into Netlify or Vercel. Build command: `npm run build`; publish directory: `dist`.

Note: The performance figures are explicitly illustrative design placeholders, not verified client results. Replace them if the company provides approved metrics.
